Guía de Instalación
Esto se hace una sola vez. El script sirve para todas las empresas: cada una queda en su propia pestaña del mismo Google Sheets.
1

Abre tu Google Sheets

Ve a la hoja de cálculo donde se guardan las respuestas. Necesitas acceso de editor (eres dueño).

2

Abre el Editor de Apps Script

En el menú superior: Extensiones → Apps Script. Se abrirá el editor.

3

Pega el código

Borra todo el código existente. Ve a la pestaña "Apps Script" de este panel, copia el código y pégalo. Guarda con Ctrl+S. Es un script genérico: no se vuelve a tocar aunque cambies preguntas o agregues otra empresa.

4

Despliega como aplicación web

Clic en Implementar → Nueva implementación → Tipo: Aplicación web → Ejecutar como: Yo → Acceso: Cualquier usuario → Implementar.

5

Autoriza los permisos

Google pedirá que autorices el script para editar tu hoja. Acepta todos los permisos.

6

Copia la URL generada

Google te dará una URL tipo https://script.google.com/macros/s/AKfy.../exec. Cópiala y pégala en Ajustes → URL del Apps Script de este panel.

7

Verifica que la URL esté viva

Ábrela en el navegador agregándole ?test=1 al final. Debe responder {"status":"ok"...}. Si sale "No se encontró la página", esa implementación no existe: regresa al paso 4 y crea una nueva.

8

Publica y prueba

Entra a Preview → Publicar encuesta, captura la clave de publicación y presiona Publicar y obtener link. La encuesta queda viva en ese instante y el panel te da el link para el personal. Ábrelo, contesta una respuesta de prueba y verifica que aparezca en la pestaña con el nombre de la empresa. No hay que subir nada a GitHub.

¿Y para la siguiente empresa?
Nada de lo anterior se repite. Cambias el nombre de la empresa y las preguntas en este panel, y presionas Publicar encuesta. Nada de repositorio ni de archivos: la encuesta nueva queda viva al instante con su propio link, y la anterior sigue funcionando con el suyo. La misma URL del Apps Script sirve para todas: cada encuesta le avisa a qué pestaña van sus respuestas.

➕3. Nueva empresa o nuevo período
El Apps Script es universal — no necesitas cambiarlo ni reimplementarlo nunca. Cada encuesta crea su propia hoja automáticamente.

Para una empresa nueva: cambia el nombre en Empresa e Identidad → publica → las respuestas van a una hoja nueva con ese nombre.

Para una segunda encuesta de la misma empresa: el sistema crea automáticamente Grupo TODA 2, Grupo TODA 3, etc.

Para cambiar preguntas: modifica en el Panel Admin → vuelve a publicar → sube el nuevo index.html a GitHub. No hay que tocar el Apps Script.

🔧7. Solución de problemas frecuentes
Las respuestas van a la hoja equivocada

Verifica que el nombre en Empresa e Identidad coincida exactamente con la hoja en Sheets. Vuelve a publicar la encuesta después de cualquier cambio de nombre.

La encuesta sigue mostrando preguntas viejas

Debes volver a publicar desde el Panel Admin y subir el nuevo index.html a GitHub. Los cambios en el panel no se reflejan automáticamente.

El dashboard no carga los datos

Verifica que la URL del Apps Script sea la correcta (termina en /exec). Si cambiaste el script, asegúrate de haber creado una nueva implementación.

El dashboard muestra datos de una encuesta anterior

Ve a 📂 Elegir Encuesta y selecciona la hoja correcta. El dashboard no cambia de hoja automáticamente.

El Panel Admin no guarda los cambios

El panel guarda automáticamente en el navegador (localStorage). Si abres el panel en otro navegador o computadora, los datos no estarán ahí — usa Exportar para hacer respaldo.
